# Lot 1 — Socle, tokens et squelette de l'app : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** créer en local le nouveau repo `ValyyuApp` (monorepo pnpm, compatible Windows) avec les tokens du design system v1, 8 composants accessibles, l'i18n française et une app Expo à onglets natifs + écran catalogue, testable dans Expo Go sur iPhone.

**Architecture :** paquets purs (`config`, `tokens`, `i18n`) testés avec Vitest ; paquet `ui` (composants React Native) et `apps/mobile` testés avec jest-expo + Testing Library. Les écrans ne contiennent aucune valeur en dur : tout passe par `@workspace/tokens`, `@workspace/config` et `@workspace/i18n`.

**Tech stack :** pnpm 10, Node 24, TypeScript (une version), Expo (SDK stable courant) + expo-router, i18next / react-i18next / expo-localization, ESLint 9 flat, Prettier, Vitest, jest-expo, @testing-library/react-native, GitHub Actions.

**Spec :** `docs/superpowers/specs/2026-10-20-lot-1-socle-design.md` · **Valeurs :** `docs/design/claude-design-v1-tokens.md`

## Global Constraints

- **Ne jamais pousser.** Pas de `git remote add`, pas de `git push`. Commits locaux uniquement.
- Repo : `/home/user/ValyyuApp`, branche de travail `develop` (créée depuis un premier commit sur `main`).
- Code, noms de fichiers, commits (Conventional Commits) et commentaires en anglais ; textes de l'app en français dans `fr.json`.
- Node 24 (`.nvmrc` = `24`), pnpm 10 (`packageManager` épinglé), `minimumReleaseAge: 1440` dans `pnpm-workspace.yaml`.
- Une seule version de TypeScript ; `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`.
- Compatible Windows : aucun script bash, uniquement Node ; `.gitattributes` `* text=auto eol=lf`.
- Scope des paquets : `@workspace/*`. **Le nom de l'app n'apparaît qu'une fois, dans `packages/config/src/app.ts`.**
- Dépendances : versions stables uniquement, licence et maintenance vérifiées, consignées dans `docs/adr/0001-stack.md`.
- Modules du lot 1 limités à ceux disponibles dans **Expo Go**.
- Styles : `start`/`end` (`marginStart`, `paddingEnd`…), jamais `left`/`right`.
- Mode clair forcé. Cible tactile ≥ 44 pt. Texte : aucune hauteur fixe, aucun `numberOfLines` sur un libellé d'action.
- Hors lot : API, base, Clerk, RevenueCat, logique métier, Sentry, Maestro, EAS.

## Review Focus

1. **Texte agrandi à 310 %** (`fontScale` 3.1) : un `Button` long doit passer sur plusieurs lignes, jamais être coupé ni déborder. → test dans la tâche 6.
2. **Langue du téléphone non prise en charge ou absente** (`de-DE`, liste vide, `undefined`) : l'app démarre en français sans erreur. → test dans la tâche 4.
3. **Futur arabe** : une propriété `left`/`right`/`marginLeft`/`paddingRight` glissée dans un style casserait le miroir. → test de scan dans la tâche 7.
4. **Bouton désactivé ou en chargement touché** : `onPress` ne doit pas être appelé et l'état doit être annoncé à VoiceOver. → test dans la tâche 6.
5. **Lien profond vers une route cachée** (`/community` avec le flag à `false`, `/dev/catalog` hors développement) : l'utilisateur ne doit pas l'atteindre. → test dans la tâche 8.
